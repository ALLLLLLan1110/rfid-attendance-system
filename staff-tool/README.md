# 内部数据管理工具

## 打开方式

双击项目根目录的 `启动数据管理.bat`。工具会自动在 Chrome 独立窗口打开，地址为 `http://127.0.0.1:8788/`。不需要先启动考勤系统，也不需要连接读卡器。需要 Windows、Node.js 22.5 及以上版本和 Chrome。

工具直接编辑 `../data/cybercard.db`，与考勤系统使用同一份数据库。保存后刷新考勤页面即可看到变化。修改考勤期间请暂停刷卡。

## 常用操作

- **学生资料**：查询、新增、编辑姓名/学号/班级、换卡、启用/停用。学生存在未签退记录时，先补充签退时间再停用。工具不提供删除学生，历史关联会保留。
- **考勤记录**：查询日期、筛选未签退、修改签到/签退时间、补记新记录。签退时间留空表示仍在校，时长自动向上取整，最少 1 分钟。已有考勤的所属学生与原卡号快照不变。
- **删除误录考勤**：在编辑窗口点击删除，输入记录编号并填写原因。删除不会删除学生，修改记录中保留原内容。
- **备份与修改记录**：手动备份、下载备份、查看每次修改的前后内容。每次实际修改前自动备份；验证失败也可能留下备份，不会写入业务记录。
- **数据表浏览**：查看全部表的原始字段、数据和字段结构。旧版网吧表仅查看，不在工具中编辑。

考勤系统通过最新的记录编号判断签到/签退，因此新补记必须晚于该学生的最后一条记录；历史纠错请编辑原记录。工具会拒绝重叠、逆序及多条未签退记录。有人在其他页面修改同一条数据时，保存会提示重新打开，避免覆盖新数据。

## 备份与恢复

备份保存在 `../data/staff-backups/`。工具使用 SQLite `VACUUM INTO` 生成完整一致快照，包含已经提交的 WAL 内容，可以在考勤系统运行时备份。下载文件是普通 SQLite 数据库。

恢复请先关闭考勤服务窗口，并在工具左下角点击「退出管理工具」。保留当前整个 `data` 文件夹作为额外备份，再用选定的 `.sqlite` 备份替换 `data/cybercard.db`。不要把旧 `cybercard.db-wal`、`cybercard.db-shm` 与恢复后的数据库混用。恢复会把所有表回到选定备份时刻，之后的修改与新增会消失；不确定时先保留文件，不要直接覆盖。

关闭 Chrome 窗口后工具的本机进程仍可能运行，再次双击会复用。左下角的「退出管理工具」可关闭工具进程，考勤系统独立运行，不受影响。日志在 `staff-tool/logs/`。

## 内部使用边界

只监听 `127.0.0.1`，不提供网络分享或账号登录。写操作要求本页面的随机会话令牌，并校验请求来源，修改记录写入 `staff_change_log` 表。它是本机维护工具，任何能使用这台电脑并打开工具的人都可以编辑；共享电脑使用后应退出工具。
