# RFID 一卡通考勤系统测试用例与风险分析

## 1. 测试环境

- Windows，Node.js 22.5+
- KL9007U / UHFReader18 系列，CP210x USB 虚拟串口
- 已验证设备：COM3，固件 02.31，功率 8 dBm
- 数据库：SQLite `data/cybercard.db`
- 页面：`http://127.0.0.1:8787/`

## 2. 功能与异常测试用例

| ID | 场景 | 前置条件 | 操作 | 预期结果 |
| --- | --- | --- | --- | --- |
| T01 | 已登记学生签到 | 学生无未签退记录 | 刷一次有效卡 | 显示签到成功；新增一条仅含签到时间的记录；当前在校 +1 |
| T02 | 已登记学生签退 | 学生存在未签退记录且已超过 10 秒 | 再刷同一张卡 | 显示签退成功；原记录补充签退时间和时长；当前在校 -1 |
| T03 | 连续重复刷卡 | 刚完成签到或签退 | 10 秒内再次提交同一卡号 | 显示重复刷卡已忽略；记录总数和原记录均不改变 |
| T04 | 陌生空白卡 | 卡号未绑定学生 | 刷卡 | 友好提示“陌生卡”；不产生考勤；可进入登记表单 |
| T05 | 登记陌生卡 | 已读取陌生卡 | 填写合法学号、姓名、班级并提交 | 学生与卡号绑定成功，并自动完成首次签到 |
| T06 | 重复学号 | 已存在相同学号 | 用另一张卡登记相同学号 | 返回“该学号已登记”；不新增学生 |
| T07 | 重复卡号 | 卡已绑定学生 | 再次登记相同卡号 | 返回“该卡号已绑定其他学生”；不新增学生 |
| T08 | 非法卡号 | 无 | 输入 `CARD-001`、奇数长度或过短值 | 返回无效卡号；不查询、不写库、程序不崩溃 |
| T09 | 卡号大小写与空格 | 无 | 输入 `e2 00 00 17` | 规范化为 `E2000017` 后处理 |
| T10 | USB 拔出 | 系统运行且设备已连接 | 拔掉 USB | 页面显示未连接/错误；Node 服务和页面不退出；桥接自动重试 |
| T11 | USB 恢复 | 完成 T10 | 重新插入 USB，等待重试或点击重连 | 状态恢复为 COM 口已连接，可继续刷卡 |
| T12 | 历史模糊查询 | 已有多名学生记录 | 输入姓名、学号、班级或卡号片段 | 只返回匹配记录 |
| T13 | 日期查询 | 跨日期存在记录 | 选择一个日期查询 | 仅返回该本地日期的签到记录 |
| T14 | 数据库唯一保护 | 同一学生已有未签退记录 | 绕过页面并尝试直接插入第二条未签退记录 | SQLite 部分唯一索引拒绝写入 |
| T15 | 服务重启 | 已有历史数据 | 重启 Node 服务 | 历史记录仍存在；页面初始为空，不重放旧卡事件 |
| T16 | 厂商 Demo 占用串口 | Demo 已连接读卡器 | 启动本系统 | 页面报告串口无法连接，不导致 Web 服务闪退 |
| T17 | 两个快速 HTTP 请求 | 已登记学生 | 并发提交两次刷卡请求 | SQLite `BEGIN IMMEDIATE` 串行化写入；第二次被防重拦截 |
| T18 | 手工模拟事件 | 服务正常 | 点击“模拟测试卡” | 事件进入与真实卡相同的前端处理流程 |

## 3. 自动测试

执行：

```powershell
npm test
```

当前自动测试覆盖 8 项：签到/签退状态判定、10 秒重复拦截、卡号规范化、非法卡号过滤、桥接 JSON 解析和非 JSON 日志过滤。硬件断线、页面显示和完整 HTTP 流程仍需按上表手工验证。

## 4. 风险分析

| 风险 | 影响 | 当前措施 | 后续建议 |
| --- | --- | --- | --- |
| USB 松动或串口通信不稳 | 无法刷卡 | 桥接退出后 3 秒重启；页面显示状态；支持手工重连 | 增加系统日志和断线告警 |
| 同一卡被连续识别 | 重复签到/签退 | 硬件层 3 秒离场判定；服务端 10 秒业务防重；数据库唯一索引 | 将间隔做成管理员配置 |
| 卡号脏数据 | 错绑学生或污染数据库 | 仅接受 8–64 位偶数长度十六进制；统一大写 | 记录被拒绝原始帧的脱敏诊断日志 |
| 卡号被复制或伪造 | 冒名考勤 | 数据库存学生绑定关系，不信任卡内余额/资料 | 增加照片核验、管理员审计或更安全卡片认证 |
| 一卡绑定多人 | 身份混乱 | `card_uid` 唯一约束 | 增加换卡、挂失和解绑审批 |
| 同一学生多条未签退记录 | 签退判定错误 | 服务端事务 + SQLite 部分唯一索引 | 增加异常修复管理页 |
| 设备读取距离过远 | 误读附近卡片 | 功率降至 8 dBm | 现场校准天线位置与功率 |
| 数据库损坏或误删 | 历史记录丢失 | WAL 模式 | 增加停机备份、自动备份和恢复演练 |
| 本机接口被恶意调用 | 伪造签到 | 仅监听 127.0.0.1，输入校验和参数化 SQL | 增加管理员登录、CSRF 防护和审计日志 |
| 电脑时间错误 | 考勤时间失真 | 使用系统时间并以 ISO 格式入库 | 启用系统时间同步，记录时间校准事件 |
| AI 生成代码无人理解 | 答辩和维护失败 | 提供与真实函数对应的答辩说明和自动测试 | 每位组员独立演示、解释并现场修改一项规则 |
